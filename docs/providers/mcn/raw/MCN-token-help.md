Как получить токен

          

   Изменено Ср, 17 Дек, 2025 на 12:05 PM 

        

      

    

  

  

    

       

 
      

        

          

            

Используя верхнее меню, перейдите в раздел 
«Интеграции» 
→
&nbsp;
вкладка 
«Токены»
.

✅ 
Примечание:

Токен можно создать только текущему пользователю и только если у него уровень доступа — администратор в разделе&nbsp;

«Интеграции».

&nbsp;&nbsp;

Чтобы создать новый токен, нажмите кнопку 
«Создать токен»
.&nbsp;

&nbsp;&nbsp;

Чтобы обновить токен, нажмите кнопку 
«Сгенерировать новый токен»
.
&nbsp; &nbsp;

Чтобы скопировать токен, нажмите кнопку 
«Скопировать токен в буфер обмена»
.
&nbsp; 

Чтобы просмотреть токен, нажмите кнопку 
«Показать токен»
.

 В случае, когда у пользователя несколько ЛС, токен будет доступен только в том ЛС, где ЛС отмечен звёздочкой — аккаунт по умолчанию. Нажмите на звёздочку напротив ЛС, для которого нужен токен.
&nbsp;

Пользователь (с ролью - Владелец или Администратор) может сгенерировать токен только для себя.

Владелец или Администратор не может обновить токен другому пользователю.

Пользователь может не видеть вкладку 
«Токены»
, если ему не предоставлен к ней доступ или услуги 
«Интеграции»&nbsp;
не подключены.&nbsp;
