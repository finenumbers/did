Документация API

Для всех пользователей SIPOUT доступны методы api для быстрого автоматического доступа к данным и редактирования настроек, без необходимости входа в личный кабинет. Список возможностей расширяется, а документация всегда будет доступна на этой странице.
Ваш api-ключ

aece1ec03d26954212f8a222e10717d5

Если Ваш api-ключ был скомпрометирован, или Вы по какой-то другой причине хотите сменить его, в любое время может быть сгенерирован новый. Для это нажмите на кнопку ниже.
Внимание! При генерировании нового ключа, старый перестаёт действовать. Убедитесь, что он больше нигде не используется.

Основные положения

В общем виде запрос происходит по следующему url:

https://lk.sipout.net/userapi/?key=<key>&method=<method>&action=<action>[&params]
  • key - Ключ аутентификации
  • method - Запрашиваемый метод
  • action - Запрашиваемое действие
  • <params> - параметры запроса, дополнительные фильтры и другие данные, необходимые для конкретного запроса
Обязательные параметры среди дополнительных отмечены знаком *

Сервис работает в режиме REST API.
Параметры POST-запросов должны передаваться формате Multipart/form-data

Ответ приходит в виде JSON-кодированного массива, состоящего из:

  • result - значения “ok” и “bad”. Статус выполнения запроса. Обязательное поле
  • err - название ошибки для программистов.
    Возвращается в случае ошибки, пример: peer_not_found (Внутренний номер, указанный в запросе не найден)
  • err_text - необязательный, дополняет “err”. Текст ошибки в человекочитаемом формате
  • data - выходные данные запроса (если есть), у каждого в своем формате
