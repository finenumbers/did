# GetFree

Source: https://docs.exolve.ru/docs/ru/api-reference/numbering-api/getting-free-numbers/

## Метод GetFree

Примените метод GetFree для получения списка номеров, доступных для покупки.

Точка подключения:

```
POST: https://api.exolve.ru/number/v1/GetFree
```

### Авторизация

| Имя | Тип | Описание |
| --- | --- | --- |
| Authorization | string | API-ключ приложения с `Bearer` перед ним. Пример: `Bearer e***s0` |

### Входные параметры

Параметры в теле запроса (JSON). Обязательные отмечены жирным в исходной статье.

| Параметр | Тип | Описание |
| --- | --- | --- |
| **type_id** | uint32 | тип номера |
| region_id | uint32 | регион номера |
| category_id | uint32 | категория номера |
| random | boolean | `True` вернёт номера в случайном порядке |
| mask | string | маска |
| limit | uint32 | лимит выводимых строк |
| offset | uint32 | номер строки, с которой начинать выборку (начинается с 0) |

#### Маска

| Символ | Назначение |
| --- | --- |
| `.` / `_` | пропускает один символ `number_code` |
| `*` / `%` | пропускает несколько символов `number_code` |

### Выходные параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| numbers | array NumberElement | список номеров |

#### NumberElement

| Параметр | Тип | Описание |
| --- | --- | --- |
| type_name | string | наименование типа номера |
| region_name | string | имя региона |
| category_name | string | имя категории номера |
| number_code | uint64 | код номера |
| subscription_fee | float | ежемесячная абонентская плата |
| install_fee | float | единоразовая плата за подключение |
| number_options | array NumberOptions | возможности номера (звонки, SMS) |

##### NumberOptions

| Параметр | Тип | Описание |
| --- | --- | --- |
| incoming_calls | bool | входящие звонки |
| outgoing_calls | bool | исходящие звонки |
| incoming_sms | bool | входящие SMS |
| outgoing_sms | bool | исходящие SMS |

### Примеры

Москва, Обычный, Мобильный:

```json
{
    "type_id": 1104,
    "region_id": 10230,
    "category_id": 10000,
    "random": true,
    "limit": 1
}
```

```json
{
    "numbers": [
        {
            "number_code": "79300655934",
            "type_name": "DEF",
            "region_name": "Moscow",
            "category_name": "REGULAR",
            "subscription_fee": 150,
            "install_fee": 590,
            "number_options": {
                "incoming_calls": true,
                "outgoing_calls": true,
                "incoming_sms": true,
                "outgoing_sms": true
            }
        }
    ]
}
```

Санкт-Петербург, Бронзовый, Городской + mask:

```json
{
    "type_id": 1105,
    "region_id": 10182,
    "category_id": 10011,
    "random": true,
    "mask": "781221*",
    "limit": 1
}
```

Россия, Серебряный, Федеральный:

```json
{
    "type_id": 1106,
    "region_id": 10084,
    "category_id": 10022,
    "random": true,
    "limit": 1
}
```

### Возможные ошибки

| Код | Статус | Пример сообщения | Описание |
| --- | --- | --- | --- |
| 400 | Bad Request | proto: syntax error … unexpected token | пустое значение в поле `type_id` |
| 400 | Bad Request | proto: syntax error … invalid value | значение в поле `type_id` невалидно |
