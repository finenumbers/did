# Как купить номер

## 
 Покупка номера в Личном кабинете

Чтобы купить номер в Личном кабинете:
- Перейдите во вкладку «Номера» в верхнем меню аккаунта или в разделе приложения.
- Нажмите кнопку «Купить номер».
- Из выпадающего списка выберете приложение, для которого хотите приобрести номер, и нажмите кнопку “Продолжить”.
- Чтобы найти нужные вам номера, воспользуйтесь фильтром в левой части страницы.
- Отметьте номера, которые хотите приобрести, и нажмите кнопку «Купить». Вы можете приобрести до 10 номеров за одну покупку.
- Проверьте детали выбранных номеров в модальном окне и нажмите кнопку «Купить».

Посмотреть параметры купленных номеров и настроить их можно в разделе «Номера». У каждого номера есть своя карточка с деталями и настройками.

## 
 Покупка номера через API

Покупка номера через API включает в себя три шага:
- Получение списка свободных номеров для покупки — GetFree
- Бронирование номера — Lock
- Покупка номера — Buy

Ниже вы найдете описание каждого шага.

### 
 Получение списка свободных номеров

Чтобы получить список свободных номером, вам нужно отправить POST запрос на следующий URL:

```
`POST: https://api.exolve.ru/number/v1/GetFree
`
```

Тип авторизации для запроса и ключи входных данных вы можете посмотреть в нашем справочнике по получению списка свободных для покупки номеров в Numbering API.

Вы можете отправить запрос через программу Postman, через терминал, используя команду `curl` или написать запрос на любом языке программирования.

### 
 Пример получения свободных номеров из Postman

В Postman выберите тип запроса POST и подставьте URL. Во вкладке `Auth` выберите тип `Bearer Token` и подставьте токен вашего приложения в аккаунте МТС Exolve. Перейдите во вкладку `Body` и выберете формат отправляемых данных JSON. Пример:

```
`{
"type_id": 1105,
"region_id": 10230,
"category_id": 10001,
"random":true,
"mask": "7499%",
"limit": 10,
"offset": 0}
`
```

### 
 Бронирование номера

Чтобы забронировать номер перед покупкой, вам нужно отправить POST-запрос на следующий URL:

```
`POST: https://api.exolve.ru/number/v1/Lock
`
```

Тип авторизации для запроса и ключи входных данных вы можете посмотреть в нашем справочнике по бронированию номеров в Numbering API.

Вы можете отправить запрос через программу Postman, через терминал, используя команду `curl` или написать запрос на любом языке программирования.

В ответ на запрос вы получите `reserve_uid`, который нужен для покупки номера.

### 
 Пример бронирования номера из Postman

В Postman выберите тип запроса POST и подставьте URL. Во вкладе `Auth` выберите тип `Bearer Token` и подставьте токен вашего приложения в аккаунте МТС Exolve. Перейдите во вкладку `Body` и выберете формат отправляемых данных JSON. Пример:

```
`{
"number_code": 79700010074,
"seconds": 72000,
"description": "TESTING"}
`
```

### 
 Покупка забронированного номера

Чтобы купить забронированный номер, вам нужно отправить POST-запрос на следующий URL:

```
`POST: https://api.exolve.ru/number/v1/Buy
`
```

Тип авторизации для запроса и ключи входных данных вы можете посмотреть в нашем справочнике по покупке номеров в Numbering API

Вы можете отправить запрос через программу Postman, через терминал, используя команду `curl` или написать запрос на любом языке программирования.

### 
 Пример покупки бронированного номера из Postman

В Postman выберите тип запроса POST и подставьте URL. Во вкладе `Auth` выберите тип `Bearer Token` и подставьте токен вашего приложения в аккаунте МТС Exolve. Перейдите во вкладку `Body` и выберете формат отправляемых данных JSON. Пример:

```
`{
"number_code": 79700010074,
"reserve_uid": 1002019//получаете в ответе при бронировании номера
}
`
```
