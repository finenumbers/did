# Как получить API-ключ приложения

Source: https://docs.exolve.ru/docs/ru/instructions/getting-api-key

После создания приложения вы можете посмотреть и скопировать его API-ключ, чтобы управлять ресурсами (номерами) и услугами приложения через API.

Чтобы посмотреть или скопировать API-ключ:

1. Перейдите во вкладку «Приложения» в верхнем меню аккаунта.
2. Нажмите на приложение, API-ключ которого хотите посмотреть или скопировать.
3. Выберите вкладку «API-ключи» в левом меню.
4. Посмотрите API-ключ или скопируйте его, используя соответствующие кнопки справа от зашифрованного API-ключа.
