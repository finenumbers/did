# Как получить API-ключ приложения

После создания приложения вы можете посмотреть и скопировать его API-ключ, чтобы управлять ресурсами (номерами) и услугами приложения через API. Чтобы посмотреть или скопировать API-ключ выполните следующие шаги:
- Перейдите во вкладку “Приложения” в верхнем меню аккаунта.
- Нажмите на приложение, API-ключ которого хотите посмотреть или скопировать.
- Выберите вкладу “API-ключи” в левом меню.
- Посмотрите API-ключ или скопируйте его, используя соответствующие кнопки справа от зашифрованного API-ключа.
